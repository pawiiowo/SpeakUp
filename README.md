# SpeakUp 

Aplicación móvil enfocada en la gestión equitativa de participación estudiantil y reducción de la ansiedad social en el aula física.

## Estructura del Proyecto
- `/frontend`: App móvil en React Native con Expo y TypeScript.
- `/backend`: API REST y servidor de sockets en tiempo real con Node.js y Express.

## Tecnologías Principales
- Frontend: React Native, Expo, TypeScript, React Native Paper.
- Backend: Node.js, Express, Socket.io, PostgreSQL.
